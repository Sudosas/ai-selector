# NEURO.CRAFT — Interactive AI Guide

NEURO.CRAFT is an interactive guide to artificial intelligence, neural networks, and practical AI tools. Explore how neural networks work, browse a curated tool catalog, and experiment with interactive learning activities.

**[Visit the live site on GitHub Pages](https://sudosas.github.io/ai-selector/)**

## What you can explore

- A visual introduction to tokens, vector spaces, self-attention, and gradient descent.
- A catalog of AI tools for text, search, coding, images, music, and audio.
- Interactive activities, including a temperature simulator, AI fact cards, a prompt builder, and a token visualizer.
- A timeline of AI milestones, engineering jokes, and an FAQ that separates common myths from reality.
- Ukrainian and English language options, plus light and dark themes.

## Run locally

This is a static website built with HTML, CSS, and vanilla JavaScript. Clone the repository and serve its files with any static web server:

```bash
git clone https://github.com/Sudosas/ai-selector.git
cd ai-selector
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
